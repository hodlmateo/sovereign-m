What M is

sovereign-m is the open-source home of M. More parts are added as they are open-sourced. The full system is not public yet. Today's public checkout is a small local-first demo of a personal agent stack. You can read the code, run it on your own computer, and copy the shape. The notes, the bots, and the sample tape are fiction. The program runs offline. Runtime dependencies are the Python standard library.

Features

This is what is in today's public demo. It is not the full M system.

  • Cited memory. Answers come from local sample notes and list their sources. A miss is visible.
  • One job per bot. Each fictional bot has a single job, and work it must refuse.
  • An approval gate. New notes stay staged until a person approves the merge. Nothing in the gate approves itself.
  • A paper-only desk. A synthetic tape, a set of roles, and rules that can veto an entry. Paper trading only.

Quick start

These commands are from the current public README and run today's demo. Use them from the project folder after a checkout. The clone step and a plain-language walkthrough are on the Set up your own M page.

pip install -e .
python -m mlite prove
python -m mlite "when do we water the fern"
python -m mlite desk run
